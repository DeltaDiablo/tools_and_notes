8.12 Maps Not Loading in Kibana
 
Title: Maps Fail to show in Kibana

Component(s): API Docs on the CVAH Frontend

Hardware Model(s): All

Description of issue: When the user opens Maps section in Kibana, maps are not displaying with an error on the layers tab

Work Around: 
1. Click the hamburger menu next to the error indicator on the right side
2. Copy the failing map server URL (typically `https://elastic-maps-server.<controller>`)
3. Open the URL in a new browser tab or window
4. Accept the certificate warning:
    - Click "Advanced"
    - Select "Proceed to site" or "trust site"
    **you are making this a trusted site for the computer you are on, 
    from this point on the individual user will have maps available in Kibana**
5. Verify the elastic-maps-server status page loads
    - you should see the elastic-maps-server home page with the current maps status.
6. Return to Kibana and refresh the maps page. 

Targeted Fix Version: N/A
