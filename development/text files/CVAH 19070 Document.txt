			Section 5.2.1 Create Disk Capacity Alert
			
			The purpose of this action is to create a custom alert for disk space usage based on your requirements or needs.
			
			1. Login to Kibana and select Hunt
			2. Under the Management section select "Stack Management" and open the Stack Management interface
			3. Under the "Alerts and Insights" on the left menu select the Rules and open the Rules interface
			4. Select the Create Rule button in the top right to start creating a rule
			5. give the new rule a name for your reference
			6. Type "Disk Usage" in the "Select Rule Type" query box 
			7. Select "Disk Usage" under stack monitoring
			8. Set the "Notify when Disk capacity is over" text box to 49% (or whatever percentage you want to be alerted to) and set the "Check every" box to 1  and the interval to minute
			9. Scroll down and under "Actions" select "Server Log"
			10. Set the values for the following Actions
				- Server Log connector: Monitoring: Write to Kibana log
				- Action frequency: On status changes
				- Level: Warning
			11. Click the "Save" Button
